# Tome XI — *The Constellation* (proposed)

*The City reads a network it did not build, and finds its own lattice already there.*

For ten tomes the Privacy Is Value Model was rendered in figures, then built by cousins, then kept warm at the Hearth. Tome XI takes the model outside. A living peer network — KwaaiNet, the Kwaai Foundation's Layer 8 fabric for shared inference and private knowledge — publishes one public document every minute: every peer its crawler can see, what each serves, how each can be reached. The Chart Shop holds that document and reads it three ways: where each peer is, what it serves, and where it sits on the 64. The third reading is new. It is the first time the model's lattice has been laid over a live decentralised trust graph that exists for private knowledge sharing, and it turns the model into something it had not been before: **a way of assessing a network**, one crawl at a time, from its boundary.

**Honest framing (binds the tome):** the map is a reading surface, not evidence. The six rules that seat a peer are a THESIS and are written down to be argued with. The weights are display registers the model itself lists as open. A key is a reading you chose; a witness is a count of attention. Nothing here is a credential, a proof, or a score.
